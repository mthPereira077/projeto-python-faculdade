# 📚 Sistema de Cálculo de Notas em Python

## 📌 Sobre o projeto

Projeto acadêmico desenvolvido durante a graduação em **Análise e Desenvolvimento de Sistemas (ADS)**.

O programa permite inserir as notas de um aluno, calcular a média e determinar automaticamente sua situação acadêmica.

## 🎯 Objetivo

Praticar conceitos fundamentais da linguagem Python, incluindo:

- Entrada de dados com `input()`
- Listas
- Estruturas de repetição (`for`)
- Estruturas condicionais (`if` / `else`)
- Funções
- Operações matemáticas
- Exibição de resultados

## 🛠️ Tecnologias utilizadas

- **Python**
- **Google Colab / Jupyter Notebook**

## ⚙️ Funcionamento

O programa solicita ao usuário a quantidade de notas que deseja inserir e, em seguida, recebe cada nota informada.

Após o preenchimento, o sistema:

1. Calcula a média das notas;
2. Verifica a situação do aluno;
3. Exibe as notas, a média e o resultado final.

A aprovação é determinada considerando média igual ou superior a 7.
